Sistema de Gestión con JPA, Hibernate y PostgreSQL

Descripción

Proyecto académico desarrollado en Java utilizando JPA e Hibernate para la persistencia de datos y PostgreSQL como sistema gestor de base de datos.

La aplicación cuenta con una interfaz gráfica desarrollada con Java Swing que permite administrar la información mediante operaciones CRUD (crear, consultar, actualizar y eliminar).

Módulos del sistema

Usuarios: registro y administración de usuarios.

Clientes: gestión de clientes asociados a usuarios.

Productos: administración de productos.

Facturas: registro de facturas relacionadas con clientes.

Detalles de factura: registro de productos y cantidades asociados a cada factura, con cálculo automático de subtotales y totales.

Tecnologías utilizadas

Java

Java Swing

JPA

Hibernate ORM

PostgreSQL

Maven

Lombok

Base de datos

Nombre: bd_ecuaquimica02

El sistema utiliza cinco entidades relacionadas: Usuario, Cliente, Producto, Factura y DetalleFactura.

Ejecución del proyecto

Clonar o descargar el repositorio.

Abrir el proyecto en NetBeans.

Configurar la conexión a PostgreSQL.

Crear la base de datos bd_ecuaquimica02.

Verificar las dependencias de Maven.

Ejecutar la clase principal ProyectoPersistencia01
